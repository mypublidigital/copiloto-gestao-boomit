# _entrada — jogue aqui o que tiver

O Claude Code lê esta pasta a cada `/autoplay`, identifica para que serve cada arquivo,
registra em `docs/progresso.md` e move o que processou para `_entrada/processados/`.
O conteúdo desta pasta **não vai para o GitHub** (só este README).

**Pode colocar:**

- Notas e respostas às perguntas do Claude Code (`.md` ou `.txt`; nome livre).
- Decisões de produto, prints de telas e referências.
- Materiais de negócio: anotações de reuniões, formato das transcrições usado pela EasyJur,
  arquivos das skills Mentor Vini e Coach de coach, descrição das alçadas.
- Acesso ou instruções da Boomit (API, repositório).

**Não coloque:**

- **Chaves, tokens e senhas.** Elas vão no `.env.local` (o Claude Code diz qual variável).
- **Dados pessoais reais** de colaboradores da EasyJur (planilhas de pessoas, avaliações,
  transcrições com nomes) antes do contrato de tratamento de dados. Até lá, só versões
  anonimizadas.
